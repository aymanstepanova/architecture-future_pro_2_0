# Task5Advanced

Артефакты задания 5: целевой технологический ландшафт, экономическое обоснование трансформации и roadmap внедрения Data Mesh для компании «Будущее 2.0».

Решение согласовано с Task3/Task4: целевая архитектура строится вокруг доменных data products, событийной платформы, управляемого доступа к данным и постепенного вывода DWH/Camel из роли центральной точки бизнес-логики.

## Состав артефактов

| Файл | Содержание |
|------|------------|
| [`tech-radar.md`](tech-radar.md) | Расширенный техрадар: технологии и архитектурные паттерны со статусами Adopt / Trial / Assess / Hold |
| [`tco-analysis.md`](tco-analysis.md) | TCO текущей и целевой архитектуры на 3 года: инфраструктура, лицензии, сопровождение, время аналитиков, миграция |
| [`roadmap.md`](roadmap.md) | Data Mesh roadmap: этапы внедрения, роли, результаты и связь с бизнес-целями |

## Self-check

- Техрадар включает не только технологии, но и паттерны: Data Mesh, Event-Driven Architecture, Self-service BI, Data Contracts, Policy-as-Code.
- Для каждого элемента техрадара указан статус `Adopt`, `Trial`, `Assess` или `Hold`.
- TCO сравнивает текущую и целевую архитектуру на горизонте 3 лет и содержит основные статьи затрат.
- Roadmap описывает пилот, масштабирование и поддержку доменов, включая роли `Data Product Owner`, `Data Engineer`, `BI-аналитик`.
- Витрина self-service не включает медицинские карты, истории болезни и сырые результаты исследований; для аналитики используются обезличенные и агрегированные data products.
- Вопросы ревьюеру по условиям задания в артефактах отсутствуют.
