# Task3Advanced

Артефакты задания 3 по целевой архитектуре данных на горизонте 3 лет.

## Состав

- `c4-containers.drawio` — C4 Level 2 (Container).
- `c4-components.drawio` — C4 Level 3 (Component) для ключевого контейнера интеграции.
- `risk-map.drawio` — визуальная карта рисков трансформации.
- `risks.md` — реестр рисков (архитектурные, организационные, технологические) с оценкой вероятности и бизнес-влияния.
- `risk-mitigation-plan.md` — план управления рисками (технологические и управленческие меры).
- `c4-containers.png` — экспорт контейнерной C4 из `c4-containers.drawio`; для ревьюера можно смотреть сразу в GitHub/GitLab без draw.io.
- `c4-components.png`  (экспорт `c4-components.drawio`) 
- `risk-map.png` (экспорт `risk-map.drawio`).

## Как открыть

1. Открыть `.drawio` в diagrams.net / draw.io desktop.
2. При необходимости экспортировать в PNG или PDF для ревью.
3. Для ревью экспортировать диаграммы в PNG/PDF из draw.io (в репозитории хранятся исходники `.drawio`).

## Соответствие критериям Task3

- C4 представлен на двух уровнях: контейнеры и компоненты.
- Риски содержат вероятность и влияние на бизнес.
- Для рисков описаны меры снижения (технологические и управленческие, в соответствии с критериями задания 3). Именованные владельцы рисков в таблицах не указаны: в кейсе не детализирована оргструктура, поэтому колонка «ответственный» намеренно не вводилась.
